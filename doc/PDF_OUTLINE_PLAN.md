# PDF 目录解析与跳转开发计划

## 1. 开发目标

为 PDF 阅读器增加目录解析功能。打开 PDF 后读取文档内置目录，在阅读器中展示层级结构；用户点击目录条目后，直接跳转到对应页面，并兼容当前的单页阅读和双页阅读模式。

## 2. 功能范围

- 使用 PDF.js 读取 PDF 内置 outline 数据。
- 展示目录标题、层级和展开/折叠状态。
- 支持目录条目点击跳转到目标页。
- 目录目标页无效或无法解析时，保留条目但不可跳转，并避免影响正文阅读。
- 双页模式下，将目标页按现有固定页对规则归一到对应页对的第一页；奇数页数 PDF 的最后一页继续单独显示。
- PDF 没有目录时显示明确的空状态。
- 目录加载失败时显示轻量错误提示，页面渲染和页码翻页仍可用。

## 3. 实施步骤

### 阶段一：目录数据模型与解析

1. 定义目录节点类型，包含标题、目标页码、层级、子节点和可跳转状态。
2. 调用 `PDFDocumentProxy.getOutline()` 获取 PDF.js 目录树。
3. 解析字符串 destination 和数组 destination，使用 PDF.js 页面索引 API 转换为从 1 开始的页码。
4. 过滤无法安全显示的空标题，保留无法解析页码的条目用于提示。
5. 将解析逻辑放入独立模块，便于单元测试和后续扩展。

### 阶段二：阅读器状态与跳转

1. 在 `PdfReader` 中增加目录数据、加载状态和错误状态。
2. PDF 文档加载完成后异步读取目录，目录读取不阻塞首屏页面渲染。
3. 增加统一的目录跳转函数，复用现有 `goToPage`、页码边界检查和滚动位置恢复逻辑。
4. 单页模式跳转到目标页；双页模式按固定页对规则归一化。
5. 跳转后更新阅读进度和当前书签状态，确保重新打开 PDF 可以恢复到最新位置。

### 阶段三：界面交互

1. 在 PDF 工具栏增加“目录”入口，并显示目录是否可用。
2. 使用独立面板或抽屉展示目录，避免遮挡页面控制栏。
3. 目录节点使用缩进表达层级，支持展开和折叠。
4. 当前页所在目录节点提供选中状态；切换页面时同步更新可见状态。
5. 可跳转条目支持鼠标和键盘操作；无目标页条目显示禁用状态和原因。
6. 面板在窄窗口、深色主题和双栏阅读布局下保持可用，不改变 PDF canvas 尺寸计算。

### 阶段四：测试与文档

1. 为目录 destination 解析补充单元测试，覆盖字符串目标、数组目标、无目标和无效目标。
2. 测试目录树层级、空目录和混合可跳转状态。
3. 测试单页与双页模式的目录跳转，以及偶数页目标归一行为。
4. 运行 `npm.cmd run lint`、`npm.cmd test` 和 `npm.cmd run build`。
5. 更新 `doc/README.md`、`doc/DESIGN.md` 和 `doc/TECHNICAL_DESIGN.md`，记录目录数据流、交互和限制。

## 4. 验收标准

- 打开带目录的 PDF 后，目录面板能够显示完整的多级目录。
- 点击可跳转目录条目后，阅读器在单页模式显示目标页。
- 双页模式点击偶数页目录目标时，显示其所属固定页对。
- 无目录 PDF 能正常打开，并显示空状态，不影响翻页、缩放、书签和批注。
- 无效目录目标不会导致 PDF 阅读器报错或白屏。
- 目录跳转后的页码能够参与进度保存和恢复。
- lint、测试和生产构建全部通过。

## 5. 后续可选优化

- 记忆目录节点的展开/折叠状态。
- 支持目录面板内标题搜索。
- 支持 PDF 外部链接目录项，在系统浏览器中打开并提示风险。
- 对超长目录进行虚拟列表渲染，减少初次渲染开销。
