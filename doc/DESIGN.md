# 书页产品设计文档

## 1. 产品定位

书页是一款面向个人用户的本地电子书阅读器。第一版优先解决“导入文件、开始阅读、保存进度、下次继续”的完整闭环，支持 PDF、TXT、只读 DOCX 和 EPUB。

## 2. MVP 用户流程

1. 用户从书架按钮或 `File > 导入书籍` 选择 PDF、TXT、DOCX 或 EPUB 文件。
2. 应用记录文件路径和基础信息，并立即打开阅读器。
3. 用户可以继续打开其他书籍，在标签栏切换，并选择一本书显示在右栏进行对照阅读。
4. 用户阅读、翻页、搜索、调整显示方式或添加书签。
5. 应用保存阅读进度；重新打开书籍时恢复上次位置。

## 3. 主要功能

### 3.1 书架

- 展示已导入书籍、格式、最近阅读时间和进度。
- 支持打开和移除书籍。
- 原文件被移动或删除后，书架保留记录并标记为不可用。

### 3.2 PDF 阅读

- 支持上一页、下一页和页码输入跳转。
- 工具栏提供“目录”入口及条目数量，异步读取 PDF 内置多级目录，加载不阻塞正文显示。
- 目录以阅读栏内的左侧浮层呈现，支持展开/折叠、当前章节高亮及自动展开当前章节的父级；浮层不改变正文缩放计算，也不会遮挡工具栏。左右阅读栏各有独立目录。
- 点击目录标题跳转到目标页顶部，双页模式按固定页对归一；跳转参与阅读进度保存和当前页书签刷新。
- 目录支持 `Tab`、`↑/↓` 移动焦点，`Enter/空格` 激活按钮，`Esc` 关闭并将焦点返回入口；在目录中操作时暂停正文翻页快捷键。
- 无目录或加载失败时显示轻量提示；无目标、无效目标和外部链接条目保留标题并显示不可跳转原因，其子级仍可展开。
- 支持单页和双页布局；双页模式按 `1-2`、`3-4` 的固定页对显示，最后一页可单独显示，翻页按一组移动。
- 默认使用“适应页面”，根据可用空间和页面尺寸自动计算缩放比例，并在窗口调整时更新。
- 支持手动缩放，手动调整后切换为手动缩放模式。
- 使用高 DPI canvas 渲染，当前按设备像素比的两倍采样，最高限制为四倍。
- 支持按当前页添加、移除和恢复书签。
- 支持 `↑/↓` 和 `PageUp/PageDown` 翻页，`B` 切换当前页书签；输入框聚焦时保留输入框默认行为。

PDF 目录只使用文档内置 outline，不从正文或扫描图像自动生成。暂不提供文本选择、重排和编辑原文功能；可以按当前页添加独立批注。

### 3.3 TXT 阅读

- 使用 `chardet` 识别编码，并使用 `iconv-lite` 解码。
- 支持滚动阅读、阅读比例恢复和当前文本关键词搜索。
- 支持添加和移除阅读位置书签。

### 3.4 Word 文档阅读

- 支持导入现代 Word `.docx` 文件，以只读纯文本方式阅读正文。
- 支持滚动、搜索、书签和阅读进度恢复；不编辑原文件、不支持旧版 `.doc` 或复杂排版还原。
- 支持按当前位置添加和删除独立批注，不改变 Word 原文件。

### 3.5 EPUB 阅读

- 解析 EPUB 包中的书籍元数据、阅读顺序（spine）、目录导航和 XHTML 章节。
- 支持章节选择、章节内搜索、书签及章节/滚动比例恢复。
- 支持 `↑/↓` 小幅滚动、`PageUp/PageDown` 按屏滚动，以及 `B` 书签快捷键。
- 以安全的语义 HTML 子集呈现章节；不执行书内脚本，不加载外部资源。
- MVP 暂不显示书内图片、EPUB 自带 CSS、音视频和外部链接，复杂排版可能与原书不同。
- 支持选择章节文字作为摘录，并与批注内容一起保存。

### 3.6 阅读设置

- 支持明亮、深色和暖黄色主题。
- 可通过颜色选择器自定义阅读区域背景色，设置持久化保存。
- 支持调整文本阅读器（TXT/DOCX）的字号和行高。
- 设置写入本地数据文件，并在下次启动时恢复。

### 3.7 多书与分栏

- 阅读页用标签栏维护当前会话中已打开的书籍，可随时切换或关闭标签。
- 当前书籍显示在左栏；通过“右栏”选择器将另一本文档放到右栏。
- 两个栏位独立加载 PDF 或文本阅读器，各自保存阅读进度、缩放、搜索和书签状态。
- 键盘翻页和 `B` 快捷键默认控制当前左栏，右栏通过其内置按钮操作。

### 3.8 读书笔记与批注

- 每条批注关联一本书和一个阅读位置，保存位置标签、可选原文摘录和用户填写的批注内容。
- TXT/EPUB 可先选择文字再打开“批注”；PDF 按当前页添加批注，避免改变 PDF canvas 或原始文件。
- 批注保存在本地 `library.json`，支持查看当前书籍的全部批注和删除批注。
- 批注入口为独立悬浮球，默认位于当前阅读区域右侧中部；悬浮球可在可见阅读区域内拖动，并在滚动阅读内容后保持在视野中。
- 点击悬浮球打开笔记面板；面板标题栏支持拖动，面板位置限制在当前阅读区域内。

## 4. 页面与交互

应用包含书架页和阅读页。Electron 的 renderer 使用 Chromium 渲染 React 界面，主进程负责窗口、文件访问和本地数据；两者通过 preload 暴露的 API 通信。阅读页顶部提供返回书架、打开书籍、已打开标签和右栏选择器；每个栏位独立展示 PDF 或文本阅读器。PDF 阅读器提供页码、布局、缩放、书签和按页批注控制；文本阅读器提供编码或 DOCX 格式信息、书签、文本选区摘录和批注控制。

批注入口以悬浮球显示在阅读区域右侧中部。悬浮球支持鼠标或触控拖动，滚动页面时保持在窗口可见范围；点击后显示笔记面板，面板标题栏也支持拖动。悬浮球和面板的位置属于当前阅读器会话状态，切换书籍后按默认位置重新定位。

## 5. 数据保存

应用只保存书籍路径、文件元数据、PDF 页码或文本类文档滚动比例、阅读设置、书签和批注。PDF/TXT/DOCX/EPUB 原文件继续由用户自行管理，应用不会复制或上传原文件；批注单独写入本地数据文件。

## 6. 暂不支持与后续方向

当前版本不包含账号、云同步、DRM、跨设备同步、语音朗读、批注编辑历史和打包发布流程。后续可完善 EPUB 图片与样式支持，并增加批注跳转和导出。

## 7. 验收标准

- 能够导入并打开 PDF、TXT、DOCX 和 EPUB；DOCX 以只读正文显示，EPUB 按章节阅读。
- PDF 能够清晰显示，支持单页、双页、适应页面和手动缩放。
- TXT 能够识别常见编码、搜索文本并恢复滚动位置。
- EPUB 能按 spine 顺序显示章节、使用目录标题，并恢复章节和滚动位置。
- 批注不会修改原始书籍，TXT/EPUB 能保存选中文本摘录，PDF 能关联当前页，并可查看、编辑和删除批注。
- 批注悬浮球默认显示在阅读区域右侧中部，滚动后仍保持可见；悬浮球和笔记面板均可拖动。
- PDF 可以使用键盘翻页，并可以通过按钮或 `B` 快捷键切换书签。
- 能够同时打开多本书，并在左右栏显示两本书；切换标签后仍能恢复各自状态。
- 进度、书签和设置在重启后仍然存在。
- 文件不存在或读取失败时显示可理解的错误信息，不导致窗口崩溃。
